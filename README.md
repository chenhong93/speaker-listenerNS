Code for Technical Validation  
The provided MEG data includes story-read/retell for speakers and story-listen for listeners. All MEG recordings have beed initially preprocessed using MaxFilter. The analysis codes, temporal results and preprocessed data (filtered/source estimate/feature-induced data) for Technical Validation are also provided.  

Sofeware  
  MATLAB R2025a  
  FieldTrip toolbox (version: 20231015)  
  mTRF-Toolbox (version: 2.3)  
  MNE-BIDS (version: 0.19.0)  
  MNE-Python (version: 1.5.1)  

Pipeline  
Getting Started: To build up the project, please follow these steps:  
1. Download Code: Download all the files from this repository and save them in a folder, for example, 'storyMEG/'  
2. Download Data: Download data from the shared link and save them in 'storyMEG/', resulting in two folders 'storyMEG/SLNS/' and 'storyMEG/res/'  
3. Install MATLAB Toolboxes: Install FieldTrip and mTRF if they are not installed yet.  

Run Codes  
f2-f5: corresponding to fig 2~fig 5 in the paper  
The last code files with 'plot' string can be runned directly with downloaded data to plot figures in the paper.  
Previous code files are used for generating the result files
